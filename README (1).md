# Tableau dashboard recipe

1. Run `python python/analyze_routes.py` from the repository root.
2. Connect Tableau Desktop to `outputs/scenario_comparison.csv`.
3. Create a KPI view with the following dimensions/measures:
   - Scenario (`scenario_id`), source (`origin_id`), status
   - Estimated Delivery Hours; Delivered Cost per Case; Route Kilometres
   - Use `selected = True` to emphasize the fastest feasible candidate.
4. Suggested visualizations: candidate-route comparison, selected route per scenario,
   delivery-time vs. cost scatterplot, stock/status alert, and scenario filter.
5. Map visualization: use `outputs/demo_route_segments.geojson` generated by Python.
   Alternatively, use `outputs/route_segments.csv` as a coordinate source and create
   a spatial line visualization with a suitable spatial connector/prepared geometry.
6. Clearly title the workbook **SYNTHETIC DEMO — NOT LIVE WILDFIRE ROUTING**.

**Important:** the route segments are straight-line demonstration connectors,
not drivable polylines, and the times/costs are synthetic. Do not describe them
as operational routes or use the mock dashboard for emergency decisions.
